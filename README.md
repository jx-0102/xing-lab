# 兴 · 终端玩具箱

> **XING LAB** —— 四个跑在终端里的小玩具，全部用 Python 自带的库写成。  
> 没有依赖，没有安装步骤，拷过去就能跑。

```
  +------------------------------------------------------------+
  |                                                            |
  |     XING  LAB   ·   兴 的 终 端 玩 具 箱                   |
  |                                                            |
  |     1   数字雨        一整屏字符往下掉，每列速度都不一样   |
  |     2   贪吃蛇        方向键控制，吃得越多跑得越快         |
  |     3   生命游戏      四条规则，长出会爬、会死的小世界     |
  |     4   大字时钟      把现在的时间画成一整屏大字           |
  |                                                            |
  |     q   退出                                               |
  |                                                            |
  +------------------------------------------------------------+
```

---

## 怎么跑起来

只要电脑上有 Python 3.7 以上（Windows 上装 Python 时记得勾 `Add to PATH`）：

```bash
python xing.py
```

按数字键进对应玩具，**不用敲回车**。每个文件也都能单独跑：

```bash
python rain.py      # 数字雨
python snake.py     # 贪吃蛇
python life.py      # 生命游戏
python clock.py     # 大字时钟
```

## 四个玩具

### 1. 数字雨 `rain.py`

一整屏字符往下掉，每一列有自己的下落速度和尾巴长度。  
头部是亮白的，尾巴从亮绿一路淡到灰，看起来像真的在下雨。

- 空格：循环切换四档速度
- q：退出

### 2. 贪吃蛇 `snake.py`

终端里的经典游戏。吃到 `*` 得 10 分，每吃一口就快一点点。

- 方向键 或 `W A S D`：控制方向
- q：退出
- 撞墙和咬到自己都会结束这一局

### 3. 生命游戏 `life.py`

康威生命游戏。规则一共只有四条：

1. 活细胞周围少于 2 个活邻居 → 死掉（太孤单）
2. 活细胞周围正好 2 或 3 个 → 活到下一代
3. 活细胞周围多于 3 个 → 死掉（太挤）
4. 死细胞周围正好 3 个 → 活过来

就这四条，屏幕上却能长出会滑行、会繁殖、会自己消失的东西。  
这一版把边界接成了环形 —— 从右边走出去，会从左边回来。

- 空格：暂停 / 继续
- n：换一批随机
- g：放一只滑翔机
- q：退出

### 4. 大字时钟 `clock.py`

把当前时间画成 5 行高的点阵大字，每秒刷新一次，底下带着日期和星期。

- q：退出

## 想加一个自己的玩具？

只要四步：

1. 新建一个 `mytoy.py`
2. 开头写 `import xt`，然后 `xt.setup()`
3. 画东西用 `xt.write()`，按键用 `xt.key_pressed()` / `xt.read_key()`
4. 最后写个 `def main(frames=None):`，再加这两行：

```python
if __name__ == "__main__":
    main(xt.frames_from_argv())
```

做完在 `xing.py` 的 `actions` 字典里加一行，它就会出现在菜单上。

**两条小经验**（踩过的坑）：

- **网格里的字符要用半角**。中文和全角符号在终端里占两格，一行里混着放就会错位。
- **重画整屏时别用清屏**，用 `xt.home()` 把光标挪回左上角再覆盖，画面才不闪。
